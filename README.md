# smart-plant-watering

식물을 키울 때 **물을 언제 줘야 하는지 기억하기 어렵다는 문제**를 해결하기 위한 간단한 식물 물주기 알림 프로그램입니다.

사용자가 식물 이름, 마지막 물주기 날짜, 물주기 주기를 입력하면 다음 물주기 날짜를 계산하고 현재 날짜를 기준으로 물을 줘야 하는지 알려줍니다.

## 📌 프로젝트 목적

식물을 처음 키우는 사람이나 여러 식물을 관리하는 사람은 각각의 식물에 물을 줘야 하는 시기를 기억하기 어려울 수 있습니다.

이 프로젝트는 이러한 문제를 인식하고, 간단한 프로그램을 통해 **식물의 물주기 일정을 관리하는 방법**을 구현하는 것을 목적으로 합니다.

## 💡 문제인식

> "식물에 물을 언제 줘야 하는지 기억하기 어렵다."

기존에는 사용자가 직접 마지막 물주기 날짜를 기억하거나 기록해야 했습니다.

이를 해결하기 위해 식물별 물주기 주기를 입력받아 다음 물주기 날짜를 자동으로 계산하도록 설계했습니다.

## ⚙️ 주요 기능

* 🌱 식물 이름 입력
* 📅 마지막 물주기 날짜 입력
* 💧 물주기 주기 입력
* 🗓️ 다음 물주기 날짜 자동 계산
* ⏰ 물주기까지 남은 날짜 표시
* 🚨 물을 줘야 하는 날인지 알려주는 알림

## 🛠️ 사용 기술

* Python 3
* datetime 라이브러리

## ▶️ 실행 방법

### 1. Python 설치

Python 3가 설치되어 있어야 합니다.

### 2. 저장소 다운로드

GitHub 저장소를 다운로드하거나 Clone합니다.

```bash
git clone https://github.com/사용자이름/smart-plant-watering.git
cd smart-plant-watering
```

### 3. 프로그램 실행

```bash
python plant_watering.py
```

## 🖥️ 실행 예시

```text
🌱 식물 물주기 알림

식물 이름: 몬스테라
마지막으로 물을 준 날짜 (YYYY-MM-DD): 2026-09-15
물주기 주기 (일): 7

--------------------
🌱 식물: 몬스테라
💧 다음 물주기: 2026-09-22
⏰ 물주기까지 5일 남았습니다.
```

물을 줘야 하는 날짜가 되면 다음과 같이 표시됩니다.

```text
🌱 식물: 몬스테라
💧 다음 물주기: 2026-09-17
🚨 오늘은 물을 주세요!
```

물주기 날짜가 지난 경우:

```text
🌱 식물: 몬스테라
💧 다음 물주기: 2026-09-15
⚠️ 물주기가 2일 지났습니다!
```

## 🔄 창의적 공학설계 프로세스와의 연결

### 1. 문제인식

식물을 키울 때 물을 주는 시기를 기억하기 어렵다는 문제를 발견했습니다.

### 2. 아이디어 도출

식물의 마지막 물주기 날짜와 물주기 주기를 이용하여 다음 물주기 날짜를 알려주는 프로그램을 생각했습니다.

### 3. 설계

사용자가 필요한 정보를 입력하면 프로그램이 자동으로 다음 물주기 날짜를 계산하도록 설계했습니다.

### 4. 프로토타입

Python을 이용하여 물주기 날짜를 계산하고 알림을 출력하는 기능을 구현했습니다.

### 5. 개선

현재 프로그램은 사용자가 직접 물주기 주기를 입력해야 합니다. 향후에는 다음과 같은 기능을 추가할 수 있습니다.

* 🌿 식물 종류별 권장 물주기 자동 설정
* 💧 토양 수분 센서 연동
* 📱 스마트폰 알림 기능
* 🌡️ 온도 및 습도 측정
* ☀️ 일조량 측정
* 🤖 AI를 이용한 식물 상태 분석
* 🚿 토양 수분에 따른 자동 급수

## 🚀 향후 발전 방향

현재 프로그램은 단순한 **소프트웨어 프로토타입**입니다.

향후 실제 센서를 연결한다면,

**날짜 기반 물주기 알림**

에서

**토양 상태를 측정하여 필요한 경우에만 물을 공급하는 스마트 화분**

으로 발전시킬 수 있습니다.

```text
현재
사용자가 날짜 입력
        ↓
다음 물주기 계산
        ↓
물주기 알림

        ↓ 개선

스마트 화분
        ↓
토양 수분 센서
        ↓
식물 상태 확인
        ↓
자동 물주기 판단
        ↓
필요한 경우 자동 급수
```
